## Stack & Libraries

1. Backend (Python / FastAPI stack)
   - Framework: FastAPI
   - DB access: SQLAlchemy, raw SQL via `sqlalchemy.text`.
   - DB: Postgres + PostGIS (docker-compose uses `postgis/postgis:17-3.5`).
   - Typical Python packages you will need to install (recommended):

2. Frontend (JavaScript / React stack)
   - Runtime: Vite dev server
   - Framework: React
   - Map library: `mappls-web-maps` (Mappls web maps SDK) used to render maps and layers
   - HTTP client: `axios`
   - Icons: `lucide-react`
